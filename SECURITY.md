# Security Policy

This is an academic project. It performs no network access, stores no secrets, and reads only the
CSV files you pass to it. Event IDs are hashed with SHA-256 for position selection only; **the filter
is not a security mechanism** and must not be used for authentication, integrity, or access control.

To report a vulnerability, open a private security advisory on the GitHub repository, or contact the
maintainers listed in the repository settings. Please do not include real personal data in reports.
