# Team Contributions

This is a suggested, balanced split for four members. Names are placeholders; no work is claimed as done by any person.

| Member | Name | Suggested responsibility |
|---|---|---|
| Member 1 | Name to be added | Bloom Filter implementation and hashing (`bloom_filter.py`, `hash_functions.py`) |
| Member 2 | Name to be added | Event detector, CSV processing and CLI (`event_detector.py`, `event_generator.py`, `cli.py`) |
| Member 3 | Name to be added | Experimental design, metrics, benchmarking and plots (`metrics.py`, `experiment_runner.py`) |
| Member 4 | Name to be added | Testing, documentation, integration and GitHub maintenance (`tests/`, `docs/`, CI, README) |

**Every member should understand the whole project**, not only their module: be ready to explain the
bit array, double hashing, the `POSSIBLE_DUPLICATE` semantics, why false negatives do not occur in
normal operation, and how the experiments separate ground truth from detection. Review each other's
code and rehearse the demo together using `docs/viva_questions.md`.
